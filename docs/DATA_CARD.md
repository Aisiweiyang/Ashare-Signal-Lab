# 数据卡

默认数据来自`asg_connectors.synthetic`和`asg_connectors.market`：8家虚构公司、固定随机种子、模板文字、转载、噪声、模拟标注和合成行情。启动演示默认seed=20260907、130个事件、180个近似交易日。

模拟行情包含按潜在标签注入的反应项；因此合成数据上的相关性不能证明真实金融文本的预测力。模拟金标由潜在真值、随机标注误差与模拟仲裁构成，不是实际人工标注。

`research/fixtures`中的47条挑战与24组中英对照都是手工开发用例，已参与规则开发。它们可用于回归，不能估计真实语料泛化准确率。测试中的小型训练样例也不是模型训练成果。

`tests/integration/baselines`只保存合成研究回归断言需要的指标。v3基准来自旧合成运行的稳定字段，保留原值，不包含数据库、环境路径、访问凭据或原始历史运行目录。

内置日历为近似fixture；真实研究须使用核实的交易日历、证券身份、发布时间与可得时间。CSV导入会检查格式，不会自动认证数据真实性、授权或历史可得性。

本仓库不分发真实行情、用户上传文本、数据库或第三方数据集。使用者自行负责导入来源的授权和时间证据。原始数据修订使用新版本，缺失不补造，严格研究拒绝无法对齐的记录。具体策略见[数据治理](DATA_GOVERNANCE.md)和[研究协议](RESEARCH_PROTOCOL.md)。
