# 模型卡

## 两条独立路径

1. 交互分析：`bilingual_finance_rules_v2.1`。处理中文、英文及混合财经文本，返回分句、目标、否定、语气、数值比较、证据与复核标记。规则响应的`confidence`、`probabilities`及`predicted_return`为null；规则强度未校准。
2. 历史实验：旧词典/mock、多数类、TF-IDF分类头和可配置LLM provider。原研究配置继续使用历史语义，交互双语结果不自动写入历史实验或金标。

`tfidf_bilingual_v2_1`是可训练基线：中文jieba词、英文词/缩约词、保留千位金额与货币符号，联合字符TF-IDF并共享给三个分类头。当前仅验证构造训练样例的fit/predict与批量等价，没有真实中英金标训练、独立泛化或概率校准结果。

## 语义与限制

- 财经倾向不等于作者心理情绪，也不等于实际价格反应。
- 数值预期比较可覆盖部分同句同指标明确结构；不支持完整财报表格、所有预期在前语序、币种或会计口径。
- 跨段指代、复杂多重否定、反讽、未声明的多公司、所有英文词形和繁体表达仍可能误判；`rule_supported`不是人工确认。
- 规则标签与人工标注指南并非在每个边界案例完全等价，实际研究应先固定标签版本并独立标注。
- 历史provider缓存键未完整覆盖提示词、标题和全部参数版本；跨配置比较时应关闭缓存或使用隔离数据环境，不能把缓存命中当成新预测。
- mock不是已验证的真实LLM。真实端点、授权语料效果与实际市场收益均未由本开源快照验收。
- 历史输出中的支持/不支持标记不替代研究协议所有资格和统计条件；应逐项核对样本、时间窗、数据时点和评价来源。

可运行能力和本机检查结果见[验收记录](VALIDATION.md)。手工开发测试通过不能报告为真实准确率100%。
